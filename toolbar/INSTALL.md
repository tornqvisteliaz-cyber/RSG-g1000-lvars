# RSG toolbar

Copy the `rsg-toolbar` folder into the MSFS 2024 Community folder. Start a flight, open the toolbar, and click RSG.

The panel shows Welcome to RSG, lists VATSIM stations in range, and tunes COM1 or COM2 with the Hz radio event. It also writes `L:RSG_ATC1_MHZ` and `L:RSG_ATC1_C1` through `C8` for Pilots Deck.

Softkey labels still need the aircraft to load `G1000SoftkeyLVars.js`. The toolbar does not need `panel.xml`.
